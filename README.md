# Begüm Alakuş · Portfolyo

Kişisel portfolyo sitesi — Mobile Developer & AI Integration. Next.js (App Router) + TypeScript, TR/EN dil desteği, Resend ile iletişim formu.

## Çalıştırma

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
```

`.env.example` dosyasını `.env.local` olarak kopyalayıp Resend anahtarınla doldur.

## Teknolojiler

Next.js · TypeScript · elle yazılmış CSS · Resend
